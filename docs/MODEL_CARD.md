Model Card: Ai4Arctic MAGT Forecast Model

## 1. Цель модели

Модель предназначена для картографирования температуры верхней границы мерзлоты (MAGT, Mean Annual Ground Temperature) в арктическом регионе по спутниковым и климатическим признакам. Основная задача — создавать пространственные оценки MAGT и связанные с ними индикаторы активности мерзлоты, которые затем используются в веб-сервисе, картографировании и климатическом анализе.

### Бизнес- и исследовательские задачи

- Оценка состояния мерзлоты по территории Северной Евразии / Арктики
- Выявление локальных и региональных аномалий температуры грунта
- Поддержка климатического мониторинга, анализа деградации мерзлоты и оценки долгосрочных тенденций
- Подготовка карт для визуализации в приложении и дальнейшей эксплуатации в бекенде

### Что именно предсказывает модель

- Вход: пространственно-временные признаки, включая MODIS, ERA5, SoilGrids, рельеф и landcover-переменные
- Выход: карта MAGT для заданного периода, основанная на ConvLSTM-архитектуре
- Целевая величина: TTOP / MAGT, сформированная по физически интерпретируемой формуле с учётом landcover и латентного тепла

### Использование по назначению

Модель подходит для:

- научного анализа и картографирования мерзлоты;
- сравнения пространственных паттернов между годами;
- оценки региональных трендов и аномалий температуры грунта.

Не следует использовать модель для:

- прямого принятия индивидуальных/операционных решений без экспертной проверки;
- экстраполяции за пределы географического окна обучения;
- ситуаций с отсутствием данных, сильной облачностью, аномальными климатическими событиями или неучтёнными типами земли.

### Критерии качества и валидации

В проекте предусмотрены проверки по нескольким принципам:

- сравнение с Obu 2019;
- сопоставление с ESA CCI; 
- проверка на 33 валидационных буровых скважинах GTN-P;
- оценка по зонам мерзлоты (континуальная, прерывистая, спорадическая, без мерзлоты);
- оценка bias correction после устранения холодного смещения.

В качестве acceptance-сценария используется:

- RMSE по бурениям должен уменьшиться;
- |bias| должен быть меньше 0.3 °C;
- модель не должна явно “перегреть” регион при коррекции.

## 3. Ограничения и границы применимости

### Географические ограничения

- Область обучения ограничена диапазоном: 30–180°E, 55–78°N
- Модель рассчитана под арктическую и субарктическую мерзлотную зону
- Среднее разрешение сетки: 0.1°; это не микромасштабная модель

### Временные ограничения

- Признаковый период: 2003–2025 (в проекте обсуждается расширенный анализ до 2025 года)
- Прогнозы на будущие годы имеют более высокую неопределённость, особенно за пределами диапазона обучающих времён

### Физические и методологические ограничения

- Модель не является физически полной моделью теплопереноса; она является статистико-гибридной эмпирической моделью
- Признаки и целевая переменная завязаны на TTOP / MAGT-формулы, но не гарантируют корректность всех локальных процессов
- Условия в урбанизированных, горных, морских, сильно нарушенных или слабо измеренных районах могут быть плохо представлены

### Оценочные ограничения

- Объём точных in-situ наблюдений ограничен (33 буровых точки по данным проекта)
- Сравнение с буры и с ESA CCI показывает более высокую ошибку в некоторых регионах и по зонам
- При наличии экстремальных событий, смены растительности или климатических аномалий прогноз устойчивости может снижаться

### Рекомендуемая зона применения

Модель наиболее надёжна для:

- регионального картографирования мерзлоты;
- сравнительной оценки многолетних трендов;
- научных анализов в пределах обучающего пространственного окна.

Не рекомендуется для:

- точных локальных инженерных решений;
- строгой оценки риска на отдельных объектах без дополнительных геологических и климатических проверок.

## 4. Bias / fairness анализ

### Что означает “fairness” в этом проекте

В этом проекте нет решения по защите персональных данных или групп людей; основная проблема — не демографическая дискриминация, а пространственная и региональная справедливость модели.

Поэтому fairness оценивается через:

- ошибки по зонам мерзлоты;
- ошибки по регионам/широтам;
- устойчивость к холодному смещению (cold bias);
- качество в sparsely observed районах.

### Основной источник смещения

Проект явно учитывает, что модель наследует холодное смещение от MODIS LST и TTOP-формулы. Это фиксируется через bias correction и последующую оценку RMSE/Bias.

В документации проекта прямо отмечается:

- остаточное bias от LST может составлять около 0.8 °C;
- для устранения используется корректировка по in-situ данным и анализ трендов;
- целевое условие — уменьшение RMSE и приведение |bias| к уровню ниже 0.3 °C.

### Региональная справедливость

Модель не является “одинаково точной везде”. По проекту:

- есть разбивка метрик по зонам мерзлоты;
- прогноз хуже оценивается в некоторых зонах и при работе с редкими буровыми данными;
- bias correction служит как механизм уменьшения системного смещения, но не гарантирует одинаковую точность во всех регионах.

### Практическое заключение по fairness

Модель лучше описывает:

- широкие региональные закономерности;
- умеренные и крупные зоны перманентной мерзлоты.

Она хуже работает:

- в менее представленных местностях;
- в регионах с сложным рельефом и малым количеством наблюдений;
- в условиях аномальных климатических сигналов или сильных локальных вариаций.

### Рекомендуемые практики для снижения bias

- регулярная проверка RMSE/Bias по зонам и широтным полосам;
- проводить bias correction при обновлении входных данных;
- пересматривать пороги качества при добавлении новых регионов;
- использовать экспертную проверку для регионов с низкой плотностью наблюдений.

## 5. Версия данных

### Основные наборы данных

Проект использует сочетание спутниковых данных, климатических реанализов и in-situ наблюдений.

| Источник | Версия / описание | Использование |
|---|---|---|
| MODIS MOD13Q1 | NDVI, NDWI, NDMI, SAVI | Вегетационные и гидрологические признаки |
| MODIS MOD11A1 | LST_summer, LST_winter, LST_annual, FDD, TDD | Температурные / мерзлотные признаки |
| MOD10A1 | snow_days | Снежный покров и сезонность |
| GMTED2010 | elevation, slope, aspect | Рельеф |
| SoilGrids 2.0 | soil_oc, soil_bd, soil_clay | Почвенные свойства |
| WorldClim v2.1 | MAAT, MAP | Климатические условия |
| ERA5-Land | era5_temp, era5_precip | Реанализированные климатические данные |
| Obu 2019 | MAGT reference grid | Сравнение и валидация |
| ESA CCI | 2023 product | Дополнительная валидация |
| GTN-P boreholes | 33 clean boreholes | In-situ проверка |

### Версия пространственного тензора

Согласно документации проекта, важнейший входной набор версии выглядит так:

- `tensor_01deg_v2.npz` / расширенная версия `tensor_01deg_extended_23y.npz`
- сетка: 231×1501
- пространственный охват: 55–78°N, 30–180°E
- шаг: 0.1°
- признаки: 20 каналов
- годы: 2003–2025 (в зависимости от варианта pipeline)

Также используются:

- `y_new_rk_landcover.npz`
- `y_new_rk_landcover_extended_23y.npz`
- `maps_lh_v3.npz`
- `obu_2019_reprojected.npz`

### Версионность и воспроизводимость

Чтобы воспроизводить результаты, важно фиксировать:

- набор признаков и их порядок;
- версию target (`rk(landcover)` / Латентное тепло / bias correction);
- выбранный временной диапазон;
- и версию benchmark-набора для валидации (Obu / ESA / boreholes).

Текущая рабочая схема проекта предполагает, что модель и данные должны документироваться через:

- код пайплайна;
- фиксированный набор файлов `.npz`;
- прописанные ссылки на внешние данные и методы извлечения;
- контроль версии используемых файлов в репозитории / data-менеджменте.
