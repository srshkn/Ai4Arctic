# Архитектура модели

## ConvLSTM: краткое введение

**ConvLSTM** (Shi et al., 2015) — это LSTM-ячейка, в которой все полносвязные
операции заменены на **2D-свёртки**. Это позволяет одновременно учитывать:

- **Пространственный контекст** — через свёрточные ядра, как в обычной CNN
- **Временную динамику** — через cell state, как в LSTM

Архитектура идеальна для пространственно-временных задач (прогноз погоды,
осадков, динамики растительности, морского льда, и т.д.).

## Уравнения ConvLSTMCell

Стандартная LSTM с заменой матричных умножений на свёртки:

```
i_t = σ(W_xi ∗ x_t + W_hi ∗ h_{t-1} + b_i)         # input gate
f_t = σ(W_xf ∗ x_t + W_hf ∗ h_{t-1} + b_f)         # forget gate
o_t = σ(W_xo ∗ x_t + W_ho ∗ h_{t-1} + b_o)         # output gate
g_t = tanh(W_xg ∗ x_t + W_hg ∗ h_{t-1} + b_g)      # candidate cell

c_t = f_t ⊙ c_{t-1} + i_t ⊙ g_t
h_t = o_t ⊙ tanh(c_t)
```

где `∗` — свёртка 2D, `⊙` — поэлементное умножение.

В нашей реализации все 4 ядра свёртки объединены в одну операцию для эффективности:

```python
combined = torch.cat([x_t, h_{t-1}], dim=channels)  # (B, in_ch+hidden, H, W)
gates = Conv2d_3x3(combined)                         # (B, 4*hidden, H, W)
i, f, o, g = gates.chunk(4, dim=channels)
```

## Полная архитектура

```
Input  (B, T=4, C_in=20, H, W)
   │
   │   ┌─────────────────────────────┐
   │   │  for t in range(T):         │
   │   │      h, c = ConvLSTMCell(   │  ← один проход по 4 годам
   │   │          x[:, t], (h, c))   │     с накоплением состояния
   │   └─────────────────────────────┘
   │
   ▼   h_T: (B, 32, H, W)
BatchNorm2d(32)
   │
   ▼
Dropout2d(0.2)
   │
   ▼
Conv2d(32 → 1, kernel=1, no padding, no activation)
   │
   ▼
Output (B, H, W) — нормализованный прогноз MAGT
```

## Почему именно эта архитектура

**Преимущества:**

1. **Простота:** мало гиперпараметров, легко настроить и защитить
2. **Скорость:** 80 эпох на T4 GPU за ~30 минут
3. **Интерпретируемость:** feature importance даёт физически осмысленные результаты
4. **Достаточная ёмкость:** R² = 0.97 на эмуляции target

**Альтернативы, которые могли бы дать лучший результат:**

- Transformer-based (TimesFormer, SwinUNet) — больше параметров, сложнее обучать
- U-Net + ConvLSTM hybrid — multi-scale, но больше памяти
- Vision Transformer (ViT) — мощный, но требует много данных

Эти направления — естественное продолжение работы.

## Особенности обучения

### Masked MSE loss

Не все пиксели валидны (вода, не-Россия, NaN в признаках). Loss считается только
на валидных пикселях:

```python
def masked_mse(pred, target, mask):
    diff = (pred - target) ** 2 * mask
    return diff.sum() / (mask.sum() + 1e-8)
```

### Tile-based inference с перекрытием

Карта 231×1501 разбивается на тайлы 64×64 с шагом 32. Каждый внутренний пиксель
попадает в 4 тайла, прогнозы усредняются. Это:

1. Снижает шум — мини-ансамбль
2. Устраняет artifacts на границах тайлов
3. Улучшает финальную точность

### MC Dropout uncertainty

Для оценки неопределённости Dropout остаётся **активным** на inference:

```python
def enable_dropout(model):
    for module in model.modules():
        if isinstance(module, (nn.Dropout, nn.Dropout2d)):
            module.train()
```

Запускается 30 прогонов, итог: mean + std по пикселям. Средняя σ = 0.22 °C.

## Связь с физикой

Хотя ConvLSTM сама по себе — «чёрный ящик», в нашей работе физика встроена
**вне модели**:

1. **Target** считается по формуле TTOP с rk(landcover) — модель учится эмулировать
   эту физически осмысленную функцию
2. **Postprocessing** — добавление ΔT(landcover) для коррекции на латентную теплоту
3. **ALT** считается по формуле Стефана из TDD и E(landcover)

Это **гибридный подход**: ML учится пространственно-временным закономерностям,
физика встроена в target и постобработку. Подтверждение: feature importance
показывает, что модель опирается именно на физически релевантные признаки
(FDD, TDD, MAAT, LST), а не на случайные комбинации.
