# Ai4Arctic

Ai4Arctic — web-сервис мониторинга вечной мерзлоты.

## 🎯 Цель проекта

Автоматизировать анализ состояния мерзлоты по спутниковым данным.

✍️

## Структура проекта
```
Ai4Arctic/
│
├── .github/workflows        # CI/CD
│   └── backend.yml
│
├── backend/
│
├── frontend/
│
```
